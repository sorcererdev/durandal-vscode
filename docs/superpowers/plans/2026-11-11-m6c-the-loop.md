# durandal-vscode M6c: the loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A plan keeps itself reconciled with the code, as in durandal.nvim. Entering a plan, anything that lands (a test run, a stub, a conjure, a do, an accepted block, a review answered `done`) and a save elsewhere each send an automatic reconcile. `p c` forces one and opens the review window when readings wait. A quiet plan tells the server it is idle, which runs the claim pass's triage. The excerpt and past-do lenses work. `p o` on a journal line opens the past do behind it. In a plan, the chord-`a` menu runs the claim pass's `Check this`, `Show why` and `Show the code here`, and applies the server's other plan actions. A server stop leaves nothing of any of it standing.

**Architecture:** The rules are pure modules with no `vscode` import, unit-tested with `node --test`:
- `plans/scheduler.ts`: nvim's reconcile state machine (in flight, again, the version check, said-open, the repeated error, the 1 s entry debounce), with an injected clock.
- `plans/idle.ts`: the per-document 1 s debounce, with injected timers.
- `plans/journal.ts`: `isJournal` and a past do's pick label.
- `plans/words.ts` gains the loop's messages.

The VS Code glue is thin. The fake-lsp e2e `fake.16-loop` and the real `real.9-plans` cover it:
- `plans/reconcile.ts` (`PlanReconcile`): the scheduler's shell. It sends `olifant/plans/reconcile`, owns the three triggers, `p c`, the cancel, the auto-open of the review, and the server's own edits during a reconcile.
- `plans/idleNotes.ts`: arms `Idle` on a plan's changes and sends `olifant/plans/idle`.
- `plans/errands.ts` (`PlanErrands`): `p o` and the past-do list. `plans/lenses.ts` registers the two lens commands.
- `actions/command.ts`: the chord-`a` menu learns the plan actions (a bare command runs, an edit applies, a source action resolves).
- `applyEdit.ts` gains an `onApplied` hook. `server.ts` gains `ClientHooks.applied` and `ClientHooks.started`. The TDD runs, stubs, conjures and the review controller fire the landed bus.

**Deviations from the spec, decided here** (say each in the PR body):
1. **No second `only: ['source']` request in the chord-`a` menu.** The spec's plan-time check found that olifant 48f38ab returns every action, `source` ones included, whatever `only` says (facts §4). The menu sends one request, as it does today.
2. **The chord-`a` menu in a plan applies an action's own edit and resolves a source action**, besides running a bare command (spec §5.6 names only the command). Today a pick of `Re-fingerprint this claim` (a quickfix with an `edit`), `Mark done` or `New step below` in a plan errors with `the server sent no plan`, because the menu's review path expects a generator's plan. nvim's menu has the same error (facts §9).
3. **`ClientHooks.started`** is new: the server tells its listeners when a client starts running. It stands in for nvim's `LspAttach` (spec §5.2 trigger 1, "the client attaching while one is active").
4. **The excerpt lens folds the row `open`** (0-based), the excerpt's opening fence. Spec §5.4's `open + 1` is nvim's 1-based row (facts §7, plans.lua :794-801).
5. **A past do opened by id that comes back empty says `plans: no record behind this line`.** nvim says nothing there (its `open_errand` has no fallback for an id).
6. **A reconcile answered after its plan closed says nothing and runs nothing again.** nvim drops it the same way (an invalid buffer); the spec does not say.
7. **A remembered reconcile runs after an error too**, as after a result: the request it stands for is not lost. nvim's callback reaches the same line on both paths.
8. **The real e2e gets one deterministic verdict through `check_answers`.** `initOptions` passes `DURANDAL_CHECK_ANSWERS` from the extension host's environment as olifant's `check_answers` test hook (a file path; olifant reads it only when set). Only `test/e2e/run.ts` sets it.
9. **The fake-lsp gains `executeCommandProvider` and an `after` pause** (the notifications, then the pause, then the answer). This is how `fake.16` puts the server's own `Olifant: reconcile` edit inside a reconcile's request, as olifant does.
10. **Every reconcile ignores a result that is not an object.** The fake answers `null` when nothing is canned, so the other suites' plans reconcile quietly.

## Global Constraints

- `engines.vscode` `^1.91.0`; `@types/vscode` `1.91.0`; no new runtime dependency. Every API used must exist in 1.91.
- No file outside `src/protocol.ts` spells an `olifant/*` method string or an `olifant.*` command. `test/unit/protocol.test.ts` pins the method list; M6c adds no method.
- Pure modules import nothing from `vscode`: `plans/scheduler.ts`, `plans/idle.ts`, `plans/journal.ts`, `plans/words.ts`, `plans/settings.ts`.
- Rows are 0-based everywhere: request `row`, lens arguments, VS Code positions.
- Message strings are durandal.nvim's, verbatim (`words.ts` holds them all): `reconcile: L facts · O to review`, `plans: no past do here`, `plans: no record behind this line`, `plans: nothing is running`, `cancelled`. Numbers are JavaScript's `String(n)`.
- An automatic reconcile is silent unless it has something to say: no message when nothing landed and the open readings are as last said; a repeated error once; `-32800` never.
- An automatic reconcile never opens the review window. Only `p c` with `readings > 0` does.
- One reconcile per plan in the air at a time (olifant runs concurrent ones in parallel, facts §1): a second start while one runs is remembered, a forced one stays forced, and one more runs after the answer.
- `durandal.plans.reconcile` `"key"` sends no automatic reconcile (entry, landings, saves). `p c` still works. Idle is sent in both modes.
- After a server stop, nothing the loop said stands: in-flight reconciles, remembered ones, the save timer, the idle timers, `saidOpen`, and the last errors are dropped, and a late answer says nothing (spec §5.7).
- Durandal never saves a plan: plan writes leave it dirty (`applyServerEdit` already skips plans).
- No new context keys (the manifest test's known list stays as it is). No action-log events.
- The working hours rule applies to execution: no agent or background work 9am–5pm America/New_York, Monday to Friday.

## Review Focus

- **The plan closed (or reopened with another language) while its reconcile runs.** Nothing is said, the review does not open, nothing runs again, and the next entry reconciles afresh. Task 4's e2e changes the plan's language during a delayed forced reconcile that answers `readings: 1`.
- **The server stopped while a reconcile runs, with one remembered.** The late rejection says nothing, the remembered one never runs, and after a restart the entry reconcile goes out (the 1 s debounce was dropped too). Task 4's e2e restarts during a held reconcile.
- **Saves in a burst across files with two plans open, one hidden.** One reconcile, for the visible plan, a second after the last save; none for the hidden one, none on the plan's own save. Task 4's e2e saves `main.py` three times within 600 ms.
- **A claim-pass command that fails.** `olifant.showWhy` on an unchecked sentence answers RequestFailed `that sentence has no check yet`: it is shown as an error, and the menu does not go on to resolve or review. Task 7's e2e cans the failure.
- **Typing that never pauses, and a plan closed before its quiet second.** No idle while changes come faster than 1 s apart; none after the plan closes; exactly one after the typing stops. Task 5's unit and e2e tests pin all three.

```ts
// The reconcile state machine (durandal.nvim plans.lua reconcile :563-606, reconciled :550-558,
// entered :610-614; lsp.lua :44-51). One reconcile per plan in the air: olifant runs concurrent
// ones in parallel, so the client keeps them apart. No vscode import; the clock is injected.
import type { ReconcileResult } from '../protocol';
import { reconcileWord } from './words';

export type Start = 'send' | 'remembered' | 'skip' | 'notRunning';
export type Answer = { result: ReconcileResult | null } | { error: { code?: number; message: string } };
// After: what an answer leaves to do. again: run once more (its forced), undefined for none.
export interface After { say?: { level: 'info' | 'error'; text: string }; open: boolean; again?: boolean }

// ENTRY_MS: an entry does not reconcile again this soon after the last start (plans.lua :612)
export const ENTRY_MS = 1000;
const CANCELLED = -32800;

// State per plan. inFlight.tick: the plan's version the reconcile is for (moved on by the
// server's own edits). again: undefined none, else the remembered one's forced.
interface State {
  inFlight?: { tick: number; forced: boolean }; again?: boolean; lastStart?: number; lastError?: string; saidOpen?: number;
}

const num = (v: unknown): number => {
  const n = typeof v === 'number' ? v : typeof v === 'string' ? Number(v) : NaN;
  return Number.isFinite(n) ? n : 0;
};

export class Scheduler {
  private readonly st = new Map<string, State>();

  constructor(private readonly now: () => number) {}

  private of(uri: string): State {
    let s = this.st.get(uri);
    if (!s) this.st.set(uri, s = {});
    return s;
  }

  // start: a reconcile asked for URI at VERSION; RUNNING: a client is there to send it
  start(uri: string, forced: boolean, running: boolean, version: number): Start {
    const s = this.of(uri);
    if (s.inFlight) {
      // nvim: again = again or forced (nil or false is false; a forced one stays forced)
      s.again = s.again === true || forced;
      return 'remembered';
    }
    if (!running) return forced ? 'notRunning' : 'skip';
    s.lastStart = this.now();
    s.inFlight = { tick: version, forced };
    return 'send';
  }

  // recent: the last start was less than ENTRY_MS ago
  recent(uri: string): boolean {
    const t = this.st.get(uri)?.lastStart;
    return t !== undefined && this.now() - t < ENTRY_MS;
  }

  inFlight(uri: string): boolean { return !!this.st.get(uri)?.inFlight; }

  // ownEdit: the server's own reconcile or journal edit took the plan to VERSION during the
  // reconcile: that is not the plan moving (lsp.lua :44-51)
  ownEdit(uri: string, version: number): void {
    const f = this.st.get(uri)?.inFlight;
    if (f) f.tick = version;
  }

  // answer: the reconcile in flight on URI answered A; the plan is at VERSIONNOW
  answer(uri: string, a: Answer, versionNow: number): After {
    const s = this.of(uri);
    const f = s.inFlight;
    s.inFlight = undefined;
    const out: After = { open: false };
    if ('error' in a) {
      const { code, message } = a.error;
      if (code !== CANCELLED && (f?.forced || s.lastError !== message)) out.say = { level: 'error', text: message };
      if (code !== CANCELLED) s.lastError = message;
    } else {
      s.lastError = undefined;
      const r = a.result;
      if (r && typeof r === 'object') {
        // the server's facts were refused when the plan moved: one more, unforced (plans.lua :596)
        if (f && versionNow !== f.tick && s.again === undefined) s.again = false;
        const landed = num(r.landed);
        const open = num(r.readings);
        if (landed > 0 || open !== (s.saidOpen ?? 0)) {
          s.saidOpen = open;
          out.say = { level: 'info', text: reconcileWord(landed, open) };
        }
        out.open = !!f?.forced && open > 0;
      }
    }
    out.again = s.again;
    s.again = undefined;
    return out;
  }

  // cancel: drop the reconcile in flight on URI and the one remembered; true when one was in flight
  cancel(uri: string): boolean {
    const s = this.st.get(uri);
    if (!s?.inFlight) return false;
    s.inFlight = undefined;
    s.again = undefined;
    return true;
  }

  // forget: URI closed
  forget(uri: string): void { this.st.delete(uri); }

  // clear: the server stopped; nothing it said stands
  clear(): void { this.st.clear(); }
}
```

```ts
import * as vscode from 'vscode';
import { errorMessage } from '../errors';
import type { Landed } from '../landed';
import { Olifant } from '../protocol';
import { NOT_RUNNING, Say, Server } from '../server';
import { planHere } from './here';
import type { PlanDocs } from './planDocs';
import { Answer, Scheduler } from './scheduler';
import type { PlansOptions } from './settings';
import { NO_PLAN } from './words';

export interface ReconcileDeps {
  server: Server; say: Say; planDocs: PlanDocs; options: () => PlansOptions; landed: Landed;
  // the reconcile's readings in the review window (M5b's Reviews.open(uri, 'reconcile'))
  review(uri: string): Promise<void>;
  now?: () => number;
}

export interface PlanReconcileApi {
  // a reconcile of the plan is in the air
  inFlight(uri: string): boolean;
  // a save elsewhere is waiting its second
  saving(): boolean;
}

// the server's own edits during a reconcile (lsp.lua :44-51)
const OWN = new Set(['Olifant: reconcile', 'Olifant: journal']);
// a save elsewhere reconciles the shown plans this long after the last one (plans.lua :310-322)
const SAVED_MS = 1000;

const keyOf = (uri: string) => vscode.Uri.parse(uri).toString();
const openDoc = (uri: string) => vscode.workspace.textDocuments.find(d => d.uri.toString() === keyOf(uri));

// Flight: a reconcile in the air; gone: its answer is not wanted (cancelled, plan closed, stopped)
interface Flight { cts: vscode.CancellationTokenSource; gone: boolean }

// PlanReconcile: the scheduler's shell (M6 spec §5.2). p c forces one (its readings open the
// review); in auto mode entering a plan, anything landing, and a save elsewhere reconcile too.
export class PlanReconcile {
  private readonly sched: Scheduler;
  private readonly flights = new Map<string, Flight>();
  private saveTimer: NodeJS.Timeout | undefined;

  constructor(private readonly d: ReconcileDeps) {
    this.sched = new Scheduler(d.now ?? Date.now);
  }

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(
      vscode.commands.registerCommand('durandal.plan.reconcile', () => this.forced()),
      vscode.window.onDidChangeActiveTextEditor(ed => void this.entered(ed)),
      this.d.landed.event(() => void this.landedElsewhere()),
      vscode.workspace.onDidSaveTextDocument(doc => void this.saved(doc)),
      vscode.workspace.onDidCloseTextDocument(doc => this.closed(doc.uri.toString())),
      { dispose: () => clearTimeout(this.saveTimer) },
    );
  }

  api(): PlanReconcileApi {
    return { inFlight: uri => this.sched.inFlight(keyOf(uri)), saving: () => this.saveTimer !== undefined };
  }

  private auto(): boolean { return this.d.options().reconcile === 'auto'; }

  // forced: p c on the active plan
  async forced(): Promise<void> {
    const h = await planHere(this.d.planDocs);
    if (!h) {
      void this.d.say('error', NO_PLAN);
      return;
    }
    await this.run(h.uri, true);
  }

  // entered: a plan became the active editor, or a client started with one active (nvim BufEnter,
  // LspAttach); not again within a second of the last start
  async entered(ed: vscode.TextEditor | undefined = vscode.window.activeTextEditor): Promise<void> {
    if (!ed || !this.auto() || !(await this.d.planDocs.is(ed.document))) return;
    const uri = ed.document.uri.toString();
    if (this.sched.recent(uri)) return;
    await this.run(uri, false);
  }

  // landedElsewhere: something landed; every open plan reconciles, shown or not
  private async landedElsewhere(): Promise<void> {
    if (!this.auto()) return;
    for (const doc of [...vscode.workspace.textDocuments]) {
      if (await this.d.planDocs.is(doc)) void this.run(doc.uri.toString(), false);
    }
  }

  // saved: a file that is not a plan was saved; a second after the last such save, the plans
  // shown in an editor reconcile (the engine reads files as saved; a hidden plan waits)
  private async saved(doc: vscode.TextDocument): Promise<void> {
    if (!this.auto() || await this.d.planDocs.is(doc)) return;
    clearTimeout(this.saveTimer);
    this.saveTimer = setTimeout(() => {
      this.saveTimer = undefined;
      void this.shown();
    }, SAVED_MS);
  }

  private async shown(): Promise<void> {
    const seen = new Set<string>();
    for (const ed of vscode.window.visibleTextEditors) {
      const uri = ed.document.uri.toString();
      if (seen.has(uri)) continue;
      seen.add(uri);
      if (await this.d.planDocs.is(ed.document)) void this.run(uri, false);
    }
  }

  // run: reconcile the plan URI (FORCED: p c); one at a time per plan, the rest remembered
  async run(uri: string, forced: boolean): Promise<void> {
    const doc = openDoc(uri);
    if (!doc) return;
    const key = doc.uri.toString();
    const go = this.sched.start(key, forced, !!this.d.server.client(), doc.version);
    if (go === 'notRunning') void this.d.say('error', NOT_RUNNING);
    if (go !== 'send') return;
    const f: Flight = { cts: new vscode.CancellationTokenSource(), gone: false };
    this.flights.set(key, f);
    let a: Answer;
    try {
      a = { result: await this.d.server.request(Olifant.plansReconcile, { textDocument: { uri: key }, forced }, f.cts.token) };
    } catch (err) {
      a = { error: { code: (err as { code?: number }).code, message: errorMessage(err) } };
    } finally {
      f.cts.dispose();
      if (this.flights.get(key) === f) this.flights.delete(key);
    }
    if (f.gone) return;
    const now = openDoc(key);
    if (!now) {
      this.sched.forget(key);
      return;
    }
    const o = this.sched.answer(key, a, now.version);
    if (o.say) void this.d.say(o.say.level, o.say.text);
    if (o.open) void this.d.review(key);
    if (o.again !== undefined) void this.run(key, o.again);
  }

  // applied: a server edit applied; the reconcile's own (and the journal's) moves its plan's
  // version on, so it does not count as the plan moving
  applied(label: string | undefined, uris: vscode.Uri[]): void {
    if (!label || !OWN.has(label)) return;
    for (const u of uris) {
      const doc = openDoc(u.toString());
      if (doc) this.sched.ownEdit(doc.uri.toString(), doc.version);
    }
  }

  // cancel: the reconcile in the air on URI, and the one remembered (Plan: Cancel); true if one was
  cancel(uri: string): boolean {
    const key = keyOf(uri);
    const f = this.flights.get(key);
    this.sched.cancel(key);
    if (!f) return false;
    f.gone = true;
    f.cts.cancel();
    this.flights.delete(key);
    return true;
  }

  // a closed plan's reconcile says nothing; its state goes
  private closed(uri: string): void {
    const f = this.flights.get(uri);
    if (f) {
      f.gone = true;
      this.flights.delete(uri);
    }
    this.sched.forget(uri);
  }

  // the server stopped: nothing it said stands (spec §5.7)
  stopped(): void {
    for (const f of this.flights.values()) f.gone = true;
    this.flights.clear();
    this.sched.clear();
    clearTimeout(this.saveTimer);
    this.saveTimer = undefined;
  }
}
```

```ts
// plans.lua idle :1073-1104; M6 spec §5.3). Per plan; each change re-arms. No vscode import;
// the timers are injected.
export interface Timers { set(fn: () => void, ms: number): unknown; clear(handle: unknown): void }

export const IDLE_MS = 1000;

export class Idle {
  private readonly timers = new Map<string, unknown>();

  // fire: the plan URI is quiet; version: its version now (undefined once closed)
  constructor(
    private readonly t: Timers, private readonly fire: (uri: string) => void,
    private readonly version: (uri: string) => number | undefined, private readonly ms = IDLE_MS,
  ) {}

  // changed: URI changed and is at VERSION: a second from now, unless it changes again
  changed(uri: string, version: number): void {
    this.forget(uri);
    this.timers.set(uri, this.t.set(() => {
      this.timers.delete(uri);
      if (this.version(uri) === version) this.fire(uri);
    }, this.ms));
  }

  armed(uri: string): boolean { return this.timers.has(uri); }

  // forget: URI closed
  forget(uri: string): void {
    const h = this.timers.get(uri);
    if (h === undefined) return;
    this.t.clear(h);
    this.timers.delete(uri);
  }

  // clear: the server stopped
  clear(): void {
    for (const h of this.timers.values()) this.t.clear(h);
    this.timers.clear();
  }
}
```

```ts
import * as vscode from 'vscode';
import { Olifant } from '../protocol';
import type { Server } from '../server';
import { Idle } from './idle';
import type { PlanDocs } from './planDocs';

const openDoc = (uri: string) => vscode.workspace.textDocuments.find(d => d.uri.toString() === uri);

// PlanIdle: olifant/plans/idle a second after a plan's last change, in either reconcile mode:
// idle is the claim pass's triage, not the reconcile (M6 spec §5.3). VS Code has no insert
// mode, so every change re-arms (nvim waits for normal mode).
export class PlanIdle {
  private readonly idle: Idle;

  constructor(private readonly d: { server: Server; planDocs: PlanDocs }) {
    this.idle = new Idle(
      { set: (fn, ms) => setTimeout(fn, ms), clear: h => clearTimeout(h as NodeJS.Timeout) },
      uri => this.send(uri),
      uri => openDoc(uri)?.version,
    );
  }

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(
      vscode.workspace.onDidChangeTextDocument(e => void this.changed(e)),
      vscode.workspace.onDidCloseTextDocument(doc => this.idle.forget(doc.uri.toString())),
      { dispose: () => this.idle.clear() },
    );
  }

  // the version is read once the plan check answers, so a later change's arm is never undone by
  // an earlier one resolving after it
  private async changed(e: vscode.TextDocumentChangeEvent): Promise<void> {
    if (e.contentChanges.length === 0 || !(await this.d.planDocs.is(e.document))) return;
    if (e.document.isClosed) return;
    this.idle.changed(e.document.uri.toString(), e.document.version);
  }

  private send(uri: string): void {
    if (!this.d.server.client()) return;
    this.d.server.notify(Olifant.plansIdle, { textDocument: { uri } }).catch(() => undefined);
  }

  // the server stopped: the timers go
  stopped(): void { this.idle.clear(); }
}
```

```ts
import * as vscode from 'vscode';
import { errorMessage } from '../errors';
import { ErrandsResult, Olifant, Review } from '../protocol';
import { NOT_RUNNING, Say, Server } from '../server';
import type { Ui } from '../uiTypes';
import { runningHere } from './here';
import { errandLabel, isJournal } from './journal';
import type { PlanDocs } from './planDocs';
import { NO_PAST_DO, NO_RECORD } from './words';

export interface ErrandsDeps {
  server: Server; say: Say; ui: () => Ui; planDocs: PlanDocs;
  // a past do in the pause window, read-only (M5b's errand review)
  show(planUri: string, review: Review): void;
}

type Lc = ReturnType<Server['client']>;

// PlanErrands: the past dos behind a plan's lines (durandal.nvim review.lua open_errand, the
// olifant.plans.errand lens; M6 spec §5.4-5.5). p o on a journal line opens its do; the lens
// lists a step's.
export class PlanErrands {
  constructor(private readonly d: ErrandsDeps) {}

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(vscode.commands.registerCommand('durandal.plan.errand', () => this.here()));
  }

  // here: p o; a journal line opens the do behind it, any other line says there is none
  async here(): Promise<void> {
    const h = await runningHere(this.d);
    if (!h) return;
    if (!isJournal(h.editor.document.lineAt(h.row).text)) {
      void this.d.say('info', NO_RECORD);
      return;
    }
    await this.open(h.uri, { row: h.row }, h.lc);
  }

  // list: the lens on ROW of the plan URI: its past dos; one opens, several are picked from
  async list(uri: string, row: number): Promise<void> {
    const lc = this.d.server.client();
    if (!lc) {
      void this.d.say('error', NOT_RUNNING);
      return;
    }
    let r: ErrandsResult | null;
    try {
      r = await this.d.server.request(Olifant.plansErrands, { textDocument: { uri }, row });
    } catch (err) {
      if (this.d.server.client() === lc) void this.d.say('error', errorMessage(err));
      return;
    }
    if (this.d.server.client() !== lc) return;
    const es = Array.isArray(r?.errands) ? r.errands : [];
    if (es.length === 0) {
      void this.d.say('info', NO_PAST_DO);
      return;
    }
    const id = es.length === 1
      ? es[0].id
      : await this.d.ui().pick<string>({ title: 'past dos', items: es.map(e => ({ label: errandLabel(e), value: e.id })) });
    if (id) await this.open(uri, { id }, lc);
  }

  // open: the do by its journal ROW or ID; an error or an empty answer says there is no record
  // (nvim's otherwise); nothing after a server stop
  private async open(uri: string, which: { row: number } | { id: string }, lc: Lc): Promise<void> {
    let r: Review | null;
    try {
      r = await this.d.server.request(Olifant.plansErrand, { textDocument: { uri }, ...which });
    } catch {
      r = null;
    }
    if (this.d.server.client() !== lc) return;
    if (r && typeof r === 'object') this.d.show(uri, r);
    else void this.d.say('info', NO_RECORD);
  }
}
```

```ts
import * as vscode from 'vscode';
import { CLIENT_COMMANDS } from '../protocol';
import type { PlanErrands } from './errands';
import { toggleFoldAt } from './folds';
import type { PlanLayer } from './layer';

const keyOf = (uri: string) => vscode.Uri.parse(uri).toString();

// registerLenses: the plan lenses' two client commands (M6 spec §5.4). The library shows the
// lenses and honours workspace/codeLens/refresh; olifant.plans.review is pause/review.ts's.
export function registerLenses(
  context: vscode.ExtensionContext,
  d: { errands: Pick<PlanErrands, 'list'>; layer: Pick<PlanLayer, 'collapsedAt' | 'foldStartsAt'> },
): void {
  context.subscriptions.push(
    // [uri, open, close, live, anchor]: the excerpt's fold opens or closes
    vscode.commands.registerCommand(CLIENT_COMMANDS.planExcerpt, (uri: unknown, open: unknown) =>
      (typeof uri === 'string' && typeof open === 'number' ? excerpt(d.layer, uri, open) : undefined)),
    // [uri, row]: the step's past dos
    vscode.commands.registerCommand(CLIENT_COMMANDS.planErrand, (uri: unknown, row: unknown) =>
      (typeof uri === 'string' && typeof row === 'number' ? d.errands.list(uri, row) : undefined)),
  );
}

// excerpt: toggle the fold at the excerpt's opening fence OPEN (0-based; nvim's open + 1 is
// 1-based) in an editor on URI, made active first (the fold commands act on the focused one);
// with none visible, one opens beside
async function excerpt(layer: Pick<PlanLayer, 'collapsedAt' | 'foldStartsAt'>, uri: string, open: number): Promise<void> {
  const key = keyOf(uri);
  const shown = vscode.window.visibleTextEditors.find(e => e.document.uri.toString() === key);
  const ed = shown
    ? await vscode.window.showTextDocument(shown.document, shown.viewColumn)
    : await vscode.window.showTextDocument(vscode.Uri.parse(key), { viewColumn: vscode.ViewColumn.Beside });
  if (layer.foldStartsAt(ed, open)) await toggleFoldAt(open, !!layer.collapsedAt(ed, open));
}
```

```ts
  // (the claim pass's Check this, Show why, Show the code here: the server's go to the server);
  // in a plan, an action's own edit applies and a source action resolves to its edit
  // (Re-fingerprint this claim, Mark done, New step below). False: the review path's.
  private async direct(uri: vscode.Uri, a: CodeAction, ui: Ui): Promise<boolean> {
    if (a.command && !a.edit && a.data === undefined) {
      const { command, arguments: args = [] } = a.command;
      try {
        if ((Object.values(SERVER_COMMANDS) as string[]).includes(command)) {
          await this.d.server.request(ExecuteCommandRequest.type, { command, arguments: args });
        } else {
          await vscode.commands.executeCommand(command, ...args);
        }
      } catch (err) {
        ui.error(errorMessage(err));
      }
      return true;
    }
    const doc = vscode.workspace.textDocuments.find(d => d.uri.toString() === uri.toString());
    if (!doc || !(await this.d.planDocs?.is(doc))) return false;
    let edit = a.edit;
    if (!edit) {
      try {
        edit = (await this.d.server.request(CodeActionResolveRequest.type, a))?.edit;

      if (!edit) {

        return true;
```
