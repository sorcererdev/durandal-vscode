## Review Focus

1. A review answer whose edit touches only a source file, not the plan, while the plan is hidden: the person expects **no** notice. The plan did not change. → Task 4, test "an edit of another file only".
2. A review answer with facts and no edit, on a hidden plan: the plan changed, so the person expects the notice. → Task 4, test "facts alone".
3. An answer that changes a hidden plan through both its edit and its facts: the person expects **one** notice, not two. → Task 4, the hidden-plan test asserts the count.
4. A plan with a `do` and an `ask` running on different rows is closed: only the ask is cancelled, the do runs to its end, and its review still opens. → Task 3, the mixed test.
5. The log guard passes because it read nothing (wrong path, or the log not yet flushed): a green guard would hide every listener throw. → Task 1. `fake.17` asserts that the log exists and is non-empty, and the shrink test is seen red before the fix.

- [ ] **Step 3: The fix**

In `src/plans/verbs.ts`, replace `closed`:

```ts
  // a closed plan's verbs land nothing and say nothing; its ghosts go without an outcome. An ask
  // or a validate is cancelled: the server runs them read-only, so no work is lost (#14). A do runs
  // to its end: cancelling kills its runner mid-edit with no review to revert it; its review is
  // pushed and says the plan changed (#11)
  private closed(uri: string): void {
    for (const e of [...this.entries]) {
      if (e.uri !== uri) continue;
      e.gone = true;
      if (e.verb !== 'do') e.cts.cancel();
      this.drop(e);
    }
    this.ghosts.drop(uri);
    this.view.forget(uri);
  }
```

`gone` is set before `cancel()`, so the cancelled answer and its `-32800` say nothing (`run`'s `if (e.gone) return;`). `drop` disposes the source after the cancel, which is the same order as `cancel()` at :338-341.

// touches: whether a server edit changes the document at uri (both parsed: the server's spelling
// of a uri can differ from VS Code's)
function touches(edit: WorkspaceEdit, uri: string): boolean {
  const key = vscode.Uri.parse(uri).toString();
  const same = (u: string) => vscode.Uri.parse(u).toString() === key;
  return Object.keys(edit.changes ?? {}).some(same)
    || (edit.documentChanges ?? []).some(c => 'textDocument' in c && same(c.textDocument.uri));
}

Replace `landReview`:

```ts
  // landReview: a choose's edit (versioned: refused whole if the plan moved) and its facts; the
  // reason when VS Code or the version check refused. A plan it changed that no editor shows
  // is said (#11).
  private async landReview(planUri: string, edit: ChooseResult['edit'], facts: Fact[] | undefined): Promise<string | undefined> {
    let changed = false;
    if (edit) {
      const lc = this.d.server.client();
      if (!lc) return NOT_RUNNING;
      const done = await applyServerEdit(lc, { label: 'review', edit }, () => undefined, () => undefined);
      if (!done.applied) return done.failureReason ?? 'VS Code did not apply the edit';
      changed = touches(edit, planUri);
    }
    if (facts && facts.length > 0) {
      const doc = await vscode.workspace.openTextDocument(vscode.Uri.parse(planUri));
      const edits = factEdits(linesOf(doc), facts);
      if (edits.length > 0) {
        if (!await vscode.workspace.applyEdit(lineEdits(doc, edits))) return 'VS Code did not apply the plan facts';
        changed = true;
      }
    }
    if (changed) this.unseen(planUri);
    return undefined;
  }

  // unseen: a plan a review's answer changed, shown in no editor, is open and unsaved where the
  // person cannot see it (#11): said once, with Open. The plan is not opened for them (it would
  // cover the file they are in) and the edit is not refused (the server has moved on).
  private unseen(planUri: string): void {
    const uri = vscode.Uri.parse(planUri);
    if (vscode.window.visibleTextEditors.some(e => e.document.uri.toString() === uri.toString())) return;
    const name = uri.path.slice(uri.path.lastIndexOf('/') + 1);
    void this.d.say('info', `plan ${name} changed · unsaved`, 'Open').then(c => {
      if (c === 'Open') void vscode.window.showTextDocument(uri);
    });
  }
```
