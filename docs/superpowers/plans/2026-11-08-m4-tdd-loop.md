# durandal-vscode M4: the TDD loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** durandal.nvim's TDD loop in VS Code. Test here, test file and test all run the project's own runner and show a results document plus error diagnostics. Jump goes between a module and its test file. Stub adds a test and opens it on its name. Conjure lands a body, flashes it and marks the after-run; a paused conjure becomes a warning with Continue and Stop. Mutate marks survivors and opens a picker that stubs or waives them, and a green run re-mutates the marked units silently.

**Architecture:** As in M2 and M3, the rules sit in pure modules with no `vscode` import, unit-tested with `node --test`:
- `tdd/flights.ts`: the requests in the air, superseding, cancel reasons, and `settle` (answer, cancelled or error).
- `tdd/results.ts`: test.lua's pure half. The results text, its links, the summary, its level, and the marks a run leaves.
- `tdd/landing.ts`: conjure.lua's and stub.lua's pure half. The conjure notice, the saved word, the paused notice, the changed span, the selection's lines, the stub notice.
- `tdd/memory.ts`: mutate.lua's and survivors.lua's pure half. Survivors per document, replaced within a unit, shifted by edits, the kills between two answers, the picker's rows.

The VS Code glue is thin and covered by the fake-lsp e2e (`fake.11-tdd`) and the real one (`real.8-tdd`):
- `tdd/common.ts`: the active file and cursor, the cancellable progress.
- `tdd/marks.ts`: the two DiagnosticCollections over `memory`.
- `tdd/tests.ts`: the three run commands, the results document and its DocumentLinkProvider.
- `tdd/jump.ts`, `tdd/stub.ts`, `tdd/conjure.ts`, `tdd/mutate.ts`, `tdd/survivors.ts`.

`uiTypes.ts` gains `ask` (a notice with buttons) and `list` (a live list view). `applyServerEdit`'s `word` hears a third list: the files it left unsaved because they had unsaved edits before. `extension.ts` builds the TDD parts, cancels their requests on a server stop, and exposes `Api.tdd` for the e2e tests.

**Tech Stack:** as M1 to M3: TypeScript 5.9 (`module: node16`), `vscode-languageclient` ^11, `vscode-languageserver-protocol` 3.18.5, esbuild, `node:test` (unit), `@vscode/test-electron` + mocha ^11 (e2e), the vendored Python fake-lsp, olifant at `.olifant-ref` for the real-server suite.

## Review Focus

1. **Edits above marked survivors.** A person mutates, then adds lines above the unit, then runs the tests green or stubs from the picker. Expected: the marks, the picker's lines, the stub's position and the re-mutate's position follow the edit, as nvim's extmarks do. Pinned by Task 3's `shift` tests and Task 6's e2e "a line added above".
2. **A whole-line selection.** Selecting lines with the mouse or Shift+Down ends at column 0 of the next line. Expected: conjure sends the last selected line, not the next. Pinned by Task 2's `selectionLines` tests and Task 5's e2e.
3. **A server stop or restart during a run or a conjure.** Expected: no error notice, no "cancelled" notice, marks and the results document stay. Pinned by Task 1's `cancelAll` test and Task 4's e2e.
4. **Running from the results document or from no file.** Expected: from the results document the last run runs again (nvim test.lua :245); from no file editor, one clear error. Pinned by Task 4's e2e.
5. **The results document already open.** A red run when the results tab is open in another column. Expected: the tab updates in place and no second tab opens. Pinned by Task 4's e2e.

## Plan decisions (flag in the PR)

1. **`Ui.list` instead of `pick` with buttons.** The survivors picker updates in place (waive, re-mutate) and closes when the active editor changes, so it needs a view handle like `form`'s. `pick` still resolves once. The spec §2 named `pick` with item buttons and `onActive`.
2. **`Ui.ask`** (a notice with buttons) is added so the e2e tests can answer the paused warning's Continue / Stop.
3. **Plan-time check, library progress:** vscode-languageclient shows server progress in `ProgressLocation.Window` (progressPart.js:84), which has no Cancel button. Ours, in a Notification, stays.
4. **Plan-time check, ast-grep in CI:** `ci.yml` already installs `@ast-grep/cli@0.45.3`, so the real mutate e2e runs in CI.
5. **Cancelled requests:** `Server.request` goes to vscode-jsonrpc directly. A cancelled token sends `$/cancelRequest` and the promise rejects with the server's −32800, or with a disposed-connection error on a stop. `settle` looks at the flight's own cancel reason first, then at code −32800.
6. **`applyServerEdit`'s `word` gets a third list,** the files left unsaved because they had unsaved edits. Conjure's notice counts them as nvim's `write_landed` does.
7. **Survivor lines follow edits** (Review Focus 1). VS Code does not move a collection's diagnostics as nvim moves extmarks, so `memory.shift` does.
8. **`no tests ran` is a warning;** the spec names only green (info) and red/broken (warning).
9. **Running from the results document re-runs the last run** (nvim parity; the spec is silent).
10. **The conjure flash is one span,** from the first to the last changed line of the request's document; the cursor goes to the span's first line. nvim flashes each hunk and picks the first hunk at or after the cursor.
11. **A resume sends** `textDocument`, `position` and `resume`, without `selection`, as nvim's does.
12. **A test run's Cancel click is silent;** the spec gives cancel messages only for conjure and mutate.

```ts
import { errorMessage } from '../errors';

// Flights are the TDD requests in the air (spec §3, §6). A newer run of a kind supersedes the
// older one, a Cancel click cancels its own, and a server stop cancels them all. The reason
// decides what is said: superseded and stopped say nothing.
export type Why = 'user' | 'superseded' | 'stopped';

// Source: a cancellation source (vscode.CancellationTokenSource in the extension).
export interface Source<T> { token: T; cancel(): void; dispose(): void }

export class Flight<T> {
  why: Why | undefined;

  constructor(private readonly src: Source<T>, private readonly gone: (f: Flight<T>) => void) {}

  get token(): T { return this.src.token; }

  // cancel: the first reason stays
  cancel(why: Why): void {
    if (this.why) return;
    this.why = why;
    this.src.cancel();
  }

  // done: the answer (or the error) is in; the flight leaves the air
  done(): void {
    this.gone(this);
    this.src.dispose();
  }
}

export class Flights<T> {
  private readonly live = new Map<string, Set<Flight<T>>>();

  constructor(private readonly make: () => Source<T>) {}

  // start puts a flight of kind in the air; supersede cancels that kind's others first
  start(kind: string, supersede = false): Flight<T> {
    const set = this.live.get(kind) ?? new Set<Flight<T>>();
    this.live.set(kind, set);
    if (supersede) for (const f of [...set]) f.cancel('superseded');
    const f: Flight<T> = new Flight(this.make(), x => set.delete(x));
    set.add(f);
    return f;
  }

  cancelAll(why: Why): void {
    for (const set of this.live.values()) for (const f of [...set]) f.cancel(why);
  }

  count(kind: string): number {
    return this.live.get(kind)?.size ?? 0;
  }
}

// CANCELLED: LSP's RequestCancelled; olifant answers it when it stops a request.
export const CANCELLED = -32800;

export type Outcome<R> =
  | { kind: 'answer'; value: R }
  | { kind: 'cancelled'; why: Why | 'server' }
  | { kind: 'error'; message: string };

// settle waits for a flight's request: its answer, or why there is none. A flight we cancelled
// drops whatever comes: a late answer, the server's -32800, the connection's end.
export async function settle<T, R>(f: Flight<T>, p: Promise<R | null | undefined>, method: string): Promise<Outcome<R>> {
  try {
    const value = await p;
    if (f.why) return { kind: 'cancelled', why: f.why };
    if (value === null || value === undefined) return { kind: 'error', message: `${method} answered nothing` };
    return { kind: 'answer', value };
  } catch (err) {
    if (f.why) return { kind: 'cancelled', why: f.why };
    if ((err as { code?: unknown } | null)?.code === CANCELLED) return { kind: 'cancelled', why: 'server' };
    return { kind: 'error', message: errorMessage(err) };
  } finally {
    f.done();
  }
}
```

```ts
import { basename } from 'node:path';
import type { TestsRunResult } from '../protocol';

// results: a test run's answer as durandal.nvim's results split says it (test.lua :70-118),
// its one-line summary, and the marks it leaves (test.lua :199-217). Spec §3.

export const RESULTS_PATH = 'tests/results.txt';

const SEP = ' · ';
const seconds = (s: number) => `${(Number(s) || 0).toFixed(1)} s`;
// the framework's colour codes (pytest runs without a tty; another runner may not)
const COLOURS = new RegExp(`${String.fromCharCode(27)}\\[[\\d;]*m`, 'g');

// lines: s split on newlines without colour codes; empty lines at either end dropped (vim.split's trimempty)
function lines(s: string | null | undefined): string[] {
  const out = (s ?? '').replace(COLOURS, '').split('\n');
  while (out.length > 0 && out[0] === '') out.shift();
  while (out.length > 0 && out[out.length - 1] === '') out.pop();
  return out;
}

// nameOf: a test id's name (src/a__test.py::test_f → test_f)
export function nameOf(id: string): string {
  const i = id.indexOf('::');
  return i < 0 ? id : id.slice(i + 2);
}

export function summaryOf(a: TestsRunResult): string {
  if (a.broken) return `broken: ${lines(a.broken)[0] ?? ''}`;
  const passed = a.passed.length;
  if (a.failed.length === 0) return `${passed === 0 ? 'no tests ran' : `all ${passed} passed`}${SEP}${seconds(a.seconds)}`;
  return `${passed} passed${SEP}${a.failed.length} failed${SEP}${seconds(a.seconds)}`;
}

// isGreen: nothing broken, nothing failed, something passed (the re-mutate's trigger, test.lua :232)
export const isGreen = (a: TestsRunResult): boolean => !a.broken && a.failed.length === 0 && a.passed.length > 0;
export const levelOf = (a: TestsRunResult): 'info' | 'warn' => (isGreen(a) ? 'info' : 'warn');
// worthOpening: the document opens beside when there is something to read
export const worthOpening = (a: TestsRunResult): boolean => !!a.broken || a.failed.length > 0;

// Link: the document's line (0-based) of a failure's ✗ row, and where it points (target 1-based)
export interface Link { line: number; file: string; target: number }

export function render(a: TestsRunResult): { text: string; links: Link[] } {
  const out: string[] = [];
  const links: Link[] = [];
  if (a.broken) {
    const why = lines(a.broken);
    out.push(`broken: ${why[0] ?? ''}`);
    for (const l of why.slice(1)) out.push(`  ${l}`);
    return { text: out.join('\n') + '\n', links };
  }
  out.push(summaryOf(a));
  for (const f of a.failed) {
    out.push('');
    const file = f.file || a.file;
    if (f.line !== null) links.push({ line: out.length, file, target: f.line });
    out.push(`✗ ${nameOf(f.id)}${f.line !== null ? `  (${basename(file)}:${f.line})` : ''}`);
    for (const l of lines(f.message)) out.push(`  ${l}`);
    for (const l of lines(f.output)) out.push(`    ${l}`);
  }
  return { text: out.join('\n') + '\n', links };
}

// Mark: an error a run leaves (line 0-based)
export interface Mark { file: string; line: number; message: string }

// marksOf: each failure with a line, in its own file; a broken run of a file, line 0 of its
// file; a broken run of the project's says why in the results only
export function marksOf(a: TestsRunResult): Mark[] {
  const out: Mark[] = [];
  if (a.broken && a.scope !== 'all') out.push({ file: a.file, line: 0, message: lines(a.broken).join('\n') });
  for (const f of a.failed) {
    if (f.line === null) continue;
    out.push({ file: f.file || a.file, line: f.line - 1, message: lines(f.message).join('\n') || `✗ ${nameOf(f.id)}` });
  }
  return out;
}
```

```ts
import type { ConjureLanded } from '../protocol';

// landing: the words and spans of a conjure's or a stub's landing (durandal.nvim conjure.lua
// :117-207, stub.lua). Spec §4.

// savedWord: what a landing saved (write_landed, conjure.lua :117-128)
export function savedWord(saved: number, unsaved: number): string {
  if (unsaved === 0) return saved > 1 ? `${saved} files saved` : 'saved';
  if (saved === 0) return unsaved > 1 ? `${unsaved} files unsaved` : 'unsaved';
  return `${saved} saved, ${unsaved} unsaved`;
}

export interface Notice { level: 'info' | 'warn'; text: string }

// conjureNotice: the landing's one line (conjure.lua :188-206); written is savedWord's, or
// undefined when nothing was edited. The level is the outcome: red warns.
export function conjureNotice(a: ConjureLanded, written: string | undefined): Notice {
  const level = a.green === false ? 'warn' : 'info';
  const summary = String(a.summary);
  if (a.stopped) {
    if (written === undefined) return { level: 'info', text: 'stopped · nothing landed' };
    return { level, text: `${summary} · ${written} · undo reverts it` };
  }
  let text = `conjured · ${summary}`;
  const rungs = Array.isArray(a.rungs) ? a.rungs : [];
  // a steered landing names its round itself
  if (!summary.includes(' in round ') && ((Number(a.rounds) || 0) > 1 || rungs.length > 1)) {
    text += ` · ${a.rounds} rounds · ${rungs.join(' → ')}`;
  }
  if (written !== undefined) text += ` · ${written}`;
  return { level, text };
}

// firstSentence: the first non-blank line, up to its first sentence end
export function firstSentence(s: string): string {
  const line = (s ?? '').split('\n').map(l => l.trim()).find(l => l !== '') ?? '';
  const m = /^(.*?[.!?])(\s|$)/.exec(line);
  return m ? m[1] : line;
}

// pausedNotice: M4's word for a paused conjure (spec §4, ruling 3)
export function pausedNotice(diagnosis: string): string {
  return `conjure paused: ${firstSentence(diagnosis)} — steering arrives in a later milestone`;
}

// changedSpan: the lines of after that differ from before (0-based, inclusive): from the first
// differing line to the last; a pure deletion flashes the line where it was
export function changedSpan(before: string[], after: string[]): { first: number; last: number } | undefined {
  if (after.length === 0) return undefined;
  let top = 0;
  while (top < before.length && top < after.length && before[top] === after[top]) top++;
  if (top === before.length && top === after.length) return undefined;
  let bottom = 0;
  while (bottom < before.length - top && bottom < after.length - top
    && before[before.length - 1 - bottom] === after[after.length - 1 - bottom]) bottom++;
  const last = after.length - 1 - bottom;
  if (last < top) {
    const at = Math.min(top, after.length - 1);
    return { first: at, last: at };
  }
  return { first: top, last };
}

export interface Pos { line: number; character: number }

// selectionLines: a non-empty selection's lines, 0-based inclusive (conjure's `selection`); one
// ending at the start of a later line (a whole-line selection) stops on the line before
export function selectionLines(start: Pos, end: Pos): { start: number; end: number } | undefined {
  if (start.line === end.line && start.character === end.character) return undefined;
  const last = end.line > start.line && end.character === 0 ? end.line - 1 : end.line;
  return { start: start.line, end: last };
}

// cursorColumn: where a stubbed test's name stands on its line (column 0 when it does not)
export const cursorColumn = (text: string, name: string): number => Math.max(0, text.indexOf(name));

// stubWord: the stub's one notice (applyServerEdit's word): the files saved, then those left
// unsaved (a failed save, or unsaved edits from before)
export function stubWord(name: string, saved: string[], unsaved: string[], kept: string[]): string {
  let text = `stubbed ${name}`;
  if (saved.length > 0) text += ` · saved ${saved.join(', ')}`;
  const left = [...unsaved, ...kept];
  if (left.length > 0) text += ` · unsaved ${left.join(', ')}`;
  return text;
}
```

```ts
import type { MutateResult, MutateSurvivor, Survivor } from '../protocol';

// memory: a mutate's survivors per document (durandal.nvim's durandal_mutate marks,
// mutate.lua). An answer replaces those inside its unit's lines and other units' stay. The
// picker, waive and the re-mutate after a green run read them (spec §5). Lines 1-based, as the
// server's; edits move them as nvim's extmarks move (Review Focus 1).

export const markText = (s: MutateSurvivor): string => `${s.from} → ${s.to} survives${s.dim ? ' (likely equivalent)' : ''}`;

type Lines = { first: number; last: number };
const inside = (line: number, l: Lines) => line >= l.first && line <= l.last;

export class SurvivorMemory {
  private readonly docs = new Map<string, MutateSurvivor[]>();

  survivors(uri: string): MutateSurvivor[] {
    return [...(this.docs.get(uri) ?? [])];
  }

  within(uri: string, lines: Lines): MutateSurvivor[] {
    return this.survivors(uri).filter(s => inside(s.line, lines));
  }

  replace(uri: string, a: MutateResult): void {
    const kept = this.survivors(uri).filter(s => !inside(s.line, a.lines));
    this.set(uri, [...kept, ...a.survivors.map(s => ({ ...s }))]);
  }

  // remove: a waived survivor, the first with its line, from and to
  remove(uri: string, s: Survivor): boolean {
    const all = this.survivors(uri);
    const i = all.findIndex(x => x.line === s.line && x.from === s.from && x.to === s.to);
    if (i < 0) return false;
    all.splice(i, 1);
    this.set(uri, all);
    return true;
  }

  forget(uri: string): void {
    this.docs.delete(uri);
  }

  // shift: an edit replaced 0-based lines startLine..endLine with text holding `inserted`
  // newlines; the survivors below it move by the difference
  shift(uri: string, startLine: number, endLine: number, inserted: number): boolean {
    const delta = inserted - (endLine - startLine);
    const all = this.docs.get(uri);
    if (!all || delta === 0) return false;
    let moved = false;
    for (const s of all) {
      if (s.line - 1 > endLine) {
        s.line += delta;
        moved = true;
      }
    }
    return moved;
  }

  private set(uri: string, ss: MutateSurvivor[]): void {
    if (ss.length === 0) this.docs.delete(uri);
    else this.docs.set(uri, ss);
  }
}

// killedBetween: the marks of before that after no longer holds (mutate.lua :107-116)
export function killedBetween(before: MutateSurvivor[], after: MutateSurvivor[]): string[] {
  const key = (s: MutateSurvivor) => `${s.line}\0${markText(s)}`;
  const now = new Set(after.map(key));
  return before.filter(s => !now.has(key(s))).map(s => `${s.from} → ${s.to} on line ${s.line}`);
}

// nextMarked: the first marked line that no unit mutated again holds (mutate.lua :86-97)
export function nextMarked(survivors: MutateSurvivor[], done: Lines[]): number | undefined {
  const open = survivors.map(s => s.line).filter(l => !done.some(d => inside(l, d)));
  return open.length === 0 ? undefined : Math.min(...open);
}

// plainSurvivor: the survivor olifant/stub and olifant/waive take
export const plainSurvivor = (s: MutateSurvivor): Survivor => ({ line: s.line, operator: s.operator, from: s.from, to: s.to, mutated: s.mutated });

export interface Row { label: string; description?: string; detail: string; value: MutateSurvivor }

// rowsOf: the picker's rows (survivors.lua M.rows): the server's order, the dim ones last
export function rowsOf(ss: MutateSurvivor[]): Row[] {
  return [...ss.filter(s => !s.dim), ...ss.filter(s => s.dim)].map(s => ({
    label: `line ${s.line}  ${s.operator}  ${s.from} → ${s.to}`,
    description: s.dim ? 'likely equivalent' : undefined,
    detail: s.mutated.trim() || `${s.from} → ${s.to}`,
    value: s,
  }));
}
```

```ts
import * as vscode from 'vscode';
import { Flight, Flights } from './flights';

export const NO_FILE = 'open a file of an Olifant project first';

export type TddFlights = Flights<vscode.CancellationToken>;
export const newFlights = (): TddFlights => new Flights(() => new vscode.CancellationTokenSource());

export interface Here { editor: vscode.TextEditor; uri: string; position: { line: number; character: number } }

// here: the active editor's file and cursor, when it shows a file
export function here(): Here | undefined {
  const editor = vscode.window.activeTextEditor;
  if (!editor || editor.document.uri.scheme !== 'file') return undefined;
  const p = editor.selection.active;
  return { editor, uri: editor.document.uri.toString(), position: { line: p.line, character: p.character } };
}

// withCancel: work under a notification with a Cancel button. The library's progress for the
// server's own $/progress sits in the status bar (ProgressLocation.Window) and has none.
export function withCancel<R>(title: string, f: Flight<vscode.CancellationToken>, work: () => Promise<R>): Thenable<R> {
  return vscode.window.withProgress({ location: vscode.ProgressLocation.Notification, title, cancellable: true }, async (_p, token) => {
    const sub = token.onCancellationRequested(() => f.cancel('user'));
    try {
      return await work();
    } finally {
      sub.dispose();
    }
  });
}
```

```ts
import * as vscode from 'vscode';
import type { MutateResult, Survivor, TestsRunResult } from '../protocol';
import { markText, SurvivorMemory } from './memory';
import { marksOf } from './results';

// a diagnostic over its whole line (VS Code clamps the end to the line's length)
const FULL = 10_000;
const wholeLine = (n: number) => new vscode.Range(n, 0, n, FULL);

// Marks are the tests' and mutate's diagnostics (durandal.nvim's durandal_tests and
// durandal_mutate namespaces), source olifant. The tests' errors are cleared at each run. The
// mutate warnings stay per document until replaced, waived, or the document closes; edits
// move them (memory.shift).
export class Marks {
  readonly memory = new SurvivorMemory();
  private readonly tests = vscode.languages.createDiagnosticCollection('durandal tests');
  private readonly mutate = vscode.languages.createDiagnosticCollection('durandal mutate');

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(
      this.tests,
      this.mutate,
      vscode.workspace.onDidCloseTextDocument(d => this.forget(d.uri)),
      vscode.workspace.onDidChangeTextDocument(e => {
        const uri = e.document.uri.toString();
        let moved = false;
        for (const c of e.contentChanges) {
          moved = this.memory.shift(uri, c.range.start.line, c.range.end.line, c.text.split('\n').length - 1) || moved;
        }
        if (moved) this.draw(e.document.uri);
      }),
    );
  }

  clearTests(): void {
    this.tests.clear();
  }

  setTests(a: TestsRunResult): void {
    this.tests.clear();
    const by = new Map<string, vscode.Diagnostic[]>();
    for (const m of marksOf(a)) {
      const d = new vscode.Diagnostic(wholeLine(m.line), m.message, vscode.DiagnosticSeverity.Error);
      d.source = 'olifant';
      const k = vscode.Uri.file(m.file).toString();
      by.set(k, [...(by.get(k) ?? []), d]);
    }
    for (const [k, ds] of by) this.tests.set(vscode.Uri.parse(k), ds);
  }

  setMutate(uri: vscode.Uri, a: MutateResult): void {
    this.memory.replace(uri.toString(), a);
    this.draw(uri);
  }

  unmark(uri: vscode.Uri, s: Survivor): void {
    this.memory.remove(uri.toString(), s);
    this.draw(uri);
  }

  forget(uri: vscode.Uri): void {
    this.memory.forget(uri.toString());
    this.mutate.delete(uri);
  }

  private draw(uri: vscode.Uri): void {
    this.mutate.set(uri, this.memory.survivors(uri.toString()).map(s => {
      const d = new vscode.Diagnostic(wholeLine(s.line - 1), markText(s), vscode.DiagnosticSeverity.Warning);
      d.source = 'olifant';
      return d;
    }));
  }
}
```

```ts
import { NOT_RUNNING, Say, Server } from '../server';
import { DOC_SCHEME, tabsUnder, VirtualDocs } from '../virtualDocs';

export type Scope = 'here' | 'file' | 'all';

export interface TestsDeps {

  recheck(uri: string): void;
}

// Tests: the three runs (durandal.nvim test.lua), the results document and its links (spec §3).
// A new run cancels the one in the air; nothing is saved first (the server runs over the
// editor's text).
export class Tests implements vscode.DocumentLinkProvider {
  last: TestsRunResult | undefined;
  private lastParams: TestsRunParams | undefined;
  private links: Link[] = [];

  constructor(private readonly d: TestsDeps) {}

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(
      vscode.commands.registerCommand('durandal.test.here', () => this.run('here')),
      vscode.commands.registerCommand('durandal.test.file', () => this.run('file')),
      vscode.commands.registerCommand('durandal.test.all', () => this.run('all')),
      vscode.languages.registerDocumentLinkProvider({ scheme: DOC_SCHEME }, this),
    );
  }

  private get resultsUri(): vscode.Uri {
    return this.d.docs.uri(RESULTS_PATH);
  }

  provideDocumentLinks(doc: vscode.TextDocument): vscode.DocumentLink[] {
    if (doc.uri.toString() !== this.resultsUri.toString()) return [];
    return this.links.filter(l => l.line < doc.lineCount).map(l => {
      const link = new vscode.DocumentLink(doc.lineAt(l.line).range, vscode.Uri.file(l.file).with({ fragment: `L${l.target}` }));
      link.tooltip = `${l.file}:${l.target}`;
      return link;
    });
  }

  // params: the active file with the cursor (here) or the scope; from the results document, the
  // last run's again (test.lua :245)
  private params(scope: Scope): TestsRunParams | string {
    const doc = vscode.window.activeTextEditor?.document;
    if (doc && doc.uri.toString() === this.resultsUri.toString()) {
      return this.lastParams ?? 'no tests have run yet: run them from a module or a test file';
    }
    const ed = vscode.window.activeTextEditor;
    if (!ed || ed.document.uri.scheme !== 'file') return NO_FILE;
    const p: TestsRunParams = { textDocument: { uri: ed.document.uri.toString() } };
    if (scope === 'here') p.position = { line: ed.selection.active.line, character: ed.selection.active.character };
    else p.scope = scope;
    return p;
  }

  async run(scope: Scope): Promise<void> {
    const p = this.params(scope);
    if (typeof p === 'string') {
      void this.d.say('error', p);
      return;
    }
    if (!this.d.server.client()) {
      void this.d.say('error', NOT_RUNNING);
      return;
    }
    this.lastParams = p;
    const f = this.d.flights.start('test', true);
    this.d.marks.clearTests();
    const o = await withCancel('Durandal: testing…', f,
      () => settle(f, this.d.server.request(Olifant.testsRun, p, f.token), Olifant.testsRun.method));
    // superseded, stopped, or a Cancel click (silent for a run, plan decision 12)
    if (o.kind === 'cancelled') return;
    if (o.kind === 'error') {
      void this.d.say('error', o.message);
      return;
    }
    const a = o.value;
    this.show(a, worthOpening(a));
    void this.d.say(levelOf(a), summaryOf(a));
    if (p.scope !== 'all' && isGreen(a)) this.d.recheck(p.textDocument.uri);
  }

  // show: the answer's marks and the results document, refreshed in place; opened beside (focus
  // stays) when asked, in the tab it already has if it has one
  show(a: TestsRunResult, open: boolean): void {
    this.last = a;
    this.d.marks.setTests(a);
    const r = render(a);
    this.links = r.links;
    const uri = this.d.docs.set(RESULTS_PATH, r.text);
    if (!open) return;
    const tab = tabsUnder(this.resultsUri.path)[0];
    const column = tab ? vscode.window.tabGroups.all.find(g => g.tabs.includes(tab))?.viewColumn : undefined;
    void vscode.window.showTextDocument(uri, { viewColumn: column ?? vscode.ViewColumn.Beside, preserveFocus: true, preview: true });
  }
}
```

```ts
      void this.d.say('error', errorMessage(err));
      return;

      void this.d.say('error', `${Olifant.testsFile.method} answered nothing`);
      return;

      await vscode.window.showTextDocument(target, { viewColumn: h.editor.viewColumn, preview: false });
      return;
    }
    const doc = await vscode.workspace.openTextDocument(target.with({ scheme: 'untitled' }));
    await vscode.window.showTextDocument(doc, { viewColumn: h.editor.viewColumn, preview: false });
    const root = await findRoot(r.file);
```

```ts
import * as vscode from 'vscode';
import { applyServerEdit } from '../applyEdit';
import { errorMessage } from '../errors';
import { MutateSurvivor, Olifant, StubParams, StubResult } from '../protocol';
import { NOT_RUNNING, Say, Server } from '../server';
import { here, NO_FILE } from './common';
import { cursorColumn, stubWord } from './landing';
import { plainSurvivor } from './memory';

// Stub: a new test for the function at the cursor, or one that kills a survivor (durandal.nvim
// stub.lua). Its edit lands as every server edit does: refused if stale, files saved (M1's
// convention, spec §4); then the test file opens with the cursor on the test's name.
export class Stub {
  constructor(private readonly d: { server: Server; say: Say }) {}

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(vscode.commands.registerCommand('durandal.stub', () => this.run()));
  }

  async run(from?: { uri: string; survivor: MutateSurvivor }): Promise<void> {
    let params: StubParams;
    if (from) {
      params = {
        textDocument: { uri: from.uri }, position: { line: from.survivor.line - 1, character: 0 },
        survivor: plainSurvivor(from.survivor),
      };
    } else {
      const h = here();
      if (!h) {
        void this.d.say('error', NO_FILE);
        return;
      }
      params = { textDocument: { uri: h.uri }, position: h.position };
    }
    let r: StubResult | null;
    try {
      r = await this.d.server.request(Olifant.stub, params);
    } catch (err) {
      void this.d.say('error', errorMessage(err));
      return;
    }
    if (!r || typeof r.file !== 'string') {
      void this.d.say('error', `${Olifant.stub.method} answered nothing`);
      return;
    }
    const lc = this.d.server.client();
    if (!lc) {
      void this.d.say('error', NOT_RUNNING);
      return;
    }
    const name = String(r.name);
    const done = await applyServerEdit(lc, { label: `stub ${name}`, edit: r.edits },
      t => void this.d.say('info', t), (saved, unsaved, kept) => stubWord(name, saved, unsaved, kept));
    if (!done.applied) {
      void this.d.say('error', done.failureReason ?? 'VS Code did not apply the stub');
      return;
    }
    const ed = await vscode.window.showTextDocument(vscode.Uri.file(r.file), { preview: false });
```

```ts
import * as vscode from 'vscode';
import { applyServerEdit } from '../applyEdit';
import { ConjureLanded, ConjureParams, ConjurePaused, Olifant } from '../protocol';
import { NOT_RUNNING, Say, Server } from '../server';
import type { Ui } from '../uiTypes';
import { here, NO_FILE, TddFlights, withCancel } from './common';
import { settle } from './flights';
import { changedSpan, conjureNotice, pausedNotice, savedWord, selectionLines } from './landing';
import type { Tests } from './tests';

export interface ConjureDeps {
  server: Server; say: Say; ui: () => Ui; flights: TddFlights; tests: Tests;
  // each landing's flashed span (Api.tdd.flashes, for the e2e tests)
  flashes: { first: number; last: number }[];
}

// Conjure: a body (or the selected lines) filled until its tests pass (durandal.nvim conjure.lua,
// spec §4). A landing applies the accepted edit, flashes the changed lines, marks the after-run
// and says one line. A pause, until M5's window, is a warning with Continue and Stop.
export class Conjure {
  private readonly landed = vscode.window.createTextEditorDecorationType({
    isWholeLine: true, backgroundColor: new vscode.ThemeColor('diffEditor.insertedLineBackground'),
  });

  constructor(private readonly d: ConjureDeps) {}

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(this.landed, vscode.commands.registerCommand('durandal.conjure', () => this.run()));
  }

  async run(): Promise<void> {
    const h = here();
    if (!h) {
      void this.d.say('error', NO_FILE);
      return;
    }
    const params: ConjureParams = { textDocument: { uri: h.uri }, position: h.position };
    const sel = selectionLines(h.editor.selection.start, h.editor.selection.end);
    if (sel) params.selection = sel;
    await this.ask(params);
  }

  // ask sends a conjure (or a resume), then lands its answer or shows its pause
  private async ask(params: ConjureParams): Promise<void> {
    if (!this.d.server.client()) {
      void this.d.say('error', NOT_RUNNING);
      return;
    }
    const f = this.d.flights.start('conjure');
    const o = await withCancel('Durandal: conjuring…', f,
      () => settle(f, this.d.server.request(Olifant.conjure, params, f.token), Olifant.conjure.method));
    if (o.kind === 'cancelled') {
      if (o.why === 'user' || o.why === 'server') void this.d.say('info', 'conjure cancelled · nothing landed');
      return;
    }
    if (o.kind === 'error') {
      void this.d.say('error', o.message);
      return;
    }
    // the one branch point is the answer's shape (conjure.lua :175): {paused: {…}} or a landing.
    // ConjureLanded is open (an index signature), so `in` does not narrow: read it through the cast.
    const p = (o.value as ConjurePaused).paused;
    if (p && typeof p === 'object') {
      await this.paused(params, p);
      return;
    }
    await this.land(params, o.value as ConjureLanded);
  }

  // paused: Continue resumes (it may pause again), Stop lands nothing; dismissed, the server's
  // token expires (spec §4, ruling 3)
  private async paused(params: ConjureParams, p: ConjurePaused['paused']): Promise<void> {
    const pick = await this.d.ui().ask('warn', pausedNotice(String(p.diagnosis ?? '')), ['Continue', 'Stop']);
    if (pick !== 'Continue' && pick !== 'Stop') return;
    await this.ask({
      textDocument: params.textDocument, position: params.position,
      resume: { token: String(p.token), choice: pick === 'Continue' ? 'continue' : 'stop' },
    });
  }

  private async land(params: ConjureParams, a: ConjureLanded): Promise<void> {
    let written: string | undefined;
    if (a.edits) {
      const lc = this.d.server.client();
      if (!lc) {
        void this.d.say('error', NOT_RUNNING);
        return;
      }
      const doc = vscode.workspace.textDocuments.find(x => x.uri.toString() === params.textDocument.uri);
      const before = doc?.getText().split('\n');
      let counts = { saved: 0, unsaved: 0 };
      const done = await applyServerEdit(lc, { label: 'conjure', edit: a.edits }, () => undefined, (saved, unsaved, kept) => {
        counts = { saved: saved.length, unsaved: unsaved.length + kept.length };
        return undefined;
      });
      if (!done.applied) {
        void this.d.say('error', done.failureReason ?? 'VS Code did not apply the conjure');
        return;
      }
      written = savedWord(counts.saved, counts.unsaved);
      if (doc && before) this.flash(doc, before);
    }
    // the after-run, as a run marks it; the results refreshed if open, not opened
    if (a.tests && typeof a.tests === 'object' && !(a.stopped && !a.edits)) this.d.tests.show(a.tests, false);
    const n = conjureNotice(a, written);
    void this.d.say(n.level, n.text);
  }

  // flash: the changed lines for half a second; the cursor to the first, when its editor is active
  private flash(doc: vscode.TextDocument, before: string[]): void {
    const span = changedSpan(before, doc.getText().split('\n'));
    if (!span) return;
    this.d.flashes.push(span);
    const range = new vscode.Range(span.first, 0, span.last, 0);
    const eds = vscode.window.visibleTextEditors.filter(e => e.document === doc);
    for (const e of eds) e.setDecorations(this.landed, [range]);
    setTimeout(() => { for (const e of eds) e.setDecorations(this.landed, []); }, 500);
    const active = vscode.window.activeTextEditor;
    if (active?.document !== doc) return;
```

```ts
import * as vscode from 'vscode';
import { errorMessage } from '../errors';
import { MutateResult, MutateSurvivor, Olifant, WaiveResult } from '../protocol';
import type { Say, Server } from '../server';
import type { ListAnswer, ListItem, ListView, Ui } from '../uiTypes';
import type { Marks } from './marks';
import { plainSurvivor, rowsOf } from './memory';
import type { Stub } from './stub';

const WAIVE = { id: 'waive', icon: 'circle-slash', tooltip: 'Waive it (with a reason)' };

interface Open { uri: string; lines: { first: number; last: number }; title: string; view: ListView<MutateSurvivor> }

// Survivors: the picker over a mutate's survivors (durandal.nvim survivors.lua, spec §5). Enter
// stubs a test that kills the one picked; the item button waives it with a reason. The editor
// shows the picked one's line. It closes when the active editor changes.
export class Survivors {
  private cur: Open | undefined;
  private readonly highlight = vscode.window.createTextEditorDecorationType({
    isWholeLine: true, backgroundColor: new vscode.ThemeColor('editor.rangeHighlightBackground'),
  });

  constructor(private readonly d: { server: Server; say: Say; ui: () => Ui; marks: Marks; stub: Stub }) {}

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(this.highlight, vscode.window.onDidChangeActiveTextEditor(e => {
      if (this.cur && e?.document.uri.toString() !== this.cur.uri) this.close();
    }));
  }

  // open: the picker for an answer's unit, if it has survivors
  open(uri: vscode.Uri, a: MutateResult): void {
    this.close();
    this.show(uri.toString(), a.lines, String(a.summary));
  }

  // refresh: an open picker over the unit an answer covers follows it (the re-mutate)
  refresh(uri: vscode.Uri, a: MutateResult): void {
    const cur = this.cur;
    if (!cur || cur.uri !== uri.toString() || a.lines.last < cur.lines.first || a.lines.first > cur.lines.last) return;
    cur.lines = a.lines;
    const rows = this.d.marks.memory.within(cur.uri, cur.lines);
    if (rows.length === 0) this.close();
    else cur.view.update(this.items(rows));
  }

  private items(rows: MutateSurvivor[]): ListItem<MutateSurvivor>[] {
    return rowsOf(rows).map(r => ({ ...r, buttons: [WAIVE] }));
  }

  private show(uri: string, lines: { first: number; last: number }, title: string): void {
    const rows = this.d.marks.memory.within(uri, lines);
    if (rows.length === 0) return;
    const view = this.d.ui().list<MutateSurvivor>({
      title, placeholder: 'Enter: stub a test that kills it · the button waives it', items: this.items(rows),
      onActive: s => this.reveal(uri, s),
    }, a => this.answered(a));
    this.cur = { uri, lines, title, view };
  }

  private answered(a: ListAnswer<MutateSurvivor>): void {
    const cur = this.cur;
    if (!cur) return;
    if (a.kind === 'hidden') {
      this.cur = undefined;
      this.unhighlight();
      return;
    }
    this.close();
    if (a.kind === 'accept') void this.d.stub.run({ uri: cur.uri, survivor: a.value });
    else if (a.id === 'waive') void this.waive(cur, a.value);
  }

  // waive: a reason, then olifant/waive; empty or cancelled sends nothing. Back to the picker
  // while the module is the active editor and survivors remain.
  private async waive(cur: Open, s: MutateSurvivor): Promise<void> {
    const reason = (await this.d.ui().text({ title: `Waive ${s.from} → ${s.to} (line ${s.line}), because:`, value: '' }).result)?.trim();
    if (reason) {
      try {
        const r: WaiveResult | null = await this.d.server.request(Olifant.waive, { textDocument: { uri: cur.uri }, survivor: plainSurvivor(s), reason });
        if (r?.waived !== true) throw new Error(`${Olifant.waive.method} answered nothing`);
        this.d.marks.unmark(vscode.Uri.parse(cur.uri), s);
        void this.d.say('info', `waived: ${s.from} → ${s.to} on line ${s.line}`);
      } catch (err) {
        void this.d.say('error', errorMessage(err));
      }
    }
    if (vscode.window.activeTextEditor?.document.uri.toString() === cur.uri) this.show(cur.uri, cur.lines, cur.title);
  }

  private reveal(uri: string, s: MutateSurvivor): void {
    const ed = vscode.window.visibleTextEditors.find(e => e.document.uri.toString() === uri);
    if (!ed) return;
    const row = Math.max(0, Math.min(s.line - 1, ed.document.lineCount - 1));
    const range = new vscode.Range(row, 0, row, 0);
    ed.setDecorations(this.highlight, [range]);
    ed.revealRange(range, vscode.TextEditorRevealType.InCenterIfOutsideViewport);
  }

  private unhighlight(): void {
    for (const e of vscode.window.visibleTextEditors) e.setDecorations(this.highlight, []);
  }

  private close(): void {
    const cur = this.cur;
    this.cur = undefined;
    this.unhighlight();
    cur?.view.close();
  }
}
```

```ts
import * as vscode from 'vscode';
import { At, MutateResult, Olifant } from '../protocol';
import { NOT_RUNNING, Say, Server } from '../server';
import { here, NO_FILE, TddFlights, withCancel } from './common';
import { settle } from './flights';
import type { Marks } from './marks';
import { killedBetween, nextMarked } from './memory';
import type { Survivors } from './survivors';

const hasLines = (a: MutateResult) => !!a.lines && typeof a.lines.first === 'number' && typeof a.lines.last === 'number';

// Mutate: the unit at the cursor mutated against its tests (durandal.nvim mutate.lua, spec §5);
// each survivor a warning on its line, the picker over them. After a green run the marked units
// are mutated again, silently, and what no longer survives is said.
export class Mutate {
  constructor(private readonly d: { server: Server; say: Say; marks: Marks; flights: TddFlights; survivors: Survivors }) {}

  register(context: vscode.ExtensionContext): void {
    context.subscriptions.push(vscode.commands.registerCommand('durandal.mutate', () => this.run()));
  }

  async run(): Promise<void> {
    const h = here();
    if (!h) {
      void this.d.say('error', NO_FILE);
      return;
    }
    if (!this.d.server.client()) {
      void this.d.say('error', NOT_RUNNING);
      return;
    }
    const params: At = { textDocument: { uri: h.uri }, position: h.position };
    const f = this.d.flights.start('mutate', true);
    const o = await withCancel('Durandal: mutating…', f,
      () => settle(f, this.d.server.request(Olifant.mutate, params, f.token), Olifant.mutate.method));
    if (o.kind === 'cancelled') {
      if (o.why === 'user' || o.why === 'server') void this.d.say('info', 'mutate cancelled');
      return;
    }
    if (o.kind === 'error') {
      void this.d.say('error', o.message);
      return;
    }
    const a = o.value;
    if (!hasLines(a)) {
      void this.d.say('error', `${Olifant.mutate.method} answered without the unit's lines`);
      return;
    }
    const uri = h.editor.document.uri;
    this.d.marks.setMutate(uri, a);
    void this.d.say('info', String(a.summary));
    if ((a.survivors ?? []).length > 0 && vscode.window.activeTextEditor?.document.uri.toString() === uri.toString()) {
      this.d.survivors.open(uri, a);
    }
  }

  // recheck: after a green run of the tests of uri, the marked units of its module (uri itself,
  // or its other side by olifant/tests/file) mutated again (mutate.lua :129-142)
  async recheck(uri: string): Promise<void> {
    if (!this.d.server.client()) return;
    let target = uri;
    if (this.d.marks.memory.survivors(uri).length === 0) {
      try {
        const r = await this.d.server.request(Olifant.testsFile, { textDocument: { uri } });
        if (!r || typeof r.file !== 'string') return;
        target = vscode.Uri.file(r.file).toString();
      } catch {
        return;
      }
      if (this.d.marks.memory.survivors(target).length === 0) return;
    }
    await this.again(vscode.Uri.parse(target));
  }

  // again: one unit after another, no progress and no picker (mutate.lua :84-124); a unit whose
  // request fails keeps its marks
  private async again(uri: vscode.Uri): Promise<void> {
    const key = uri.toString();
    const killed: string[] = [];
    const done: { first: number; last: number }[] = [];
    for (;;) {
      const line = nextMarked(this.d.marks.memory.survivors(key), done);
      if (line === undefined) break;
      const f = this.d.flights.start('remutate');
      const o = await settle(f, this.d.server.request(Olifant.mutate,
        { textDocument: { uri: key }, position: { line: line - 1, character: 0 } }, f.token), Olifant.mutate.method);
      if (o.kind === 'cancelled') return;
      // the line is done whatever came: an answer for another unit cannot loop
      done.push({ first: line, last: line });
      if (o.kind === 'error' || !hasLines(o.value)) continue;
      const a = o.value;
      const before = this.d.marks.memory.within(key, a.lines);
      this.d.marks.setMutate(uri, a);
      killed.push(...killedBetween(before, this.d.marks.memory.within(key, a.lines)));
      this.d.survivors.refresh(uri, a);
      done.push(a.lines);
    }
    if (killed.length > 0) void this.d.say('info', `killed: ${killed.join('; ')}`);
  }
}
```

```markdown
## The TDD loop

The chord is Ctrl+Alt+D (Cmd+Alt+D on macOS) followed by a letter.

| Chord | Command | What it does |
|---|---|---|
| `t` | Run the Test Here | The test under the cursor; in a module, its test file. |
| `shift+t` | Run This File's Tests | The file's tests (a module's test file). |
| (palette) | Run All Tests | The project's tests. |
| `j` | Jump to Test or Module | Between a module and its test file; a missing test file opens untitled at its path. |
| `s` | Stub a Test | A new test for the function at the cursor, at the end of its test file, saved; the cursor on its name. |
| `c` | Conjure | Fills the body at the cursor, or the selected lines, until its tests pass; lands as one undo step. |
| `m` | Mutate | Mutates the unit at the cursor; survivors are warnings and a picker stubs or waives them. |

A run writes its summary as a notice and its failures as errors on their lines (F8 walks them).
The full output is in the results document, which opens beside the editor when something failed;
Ctrl/Cmd-click a `✗` line to go to it. A green run of a module's tests mutates its marked units
again and says which survivors it killed. Runs, conjures and mutates show a Cancel button. A
conjure that pauses (a decision model with a ladder) offers Continue and Stop; the steering
window comes in a later release. There is no Test Explorer: olifant lists no tests.
```
